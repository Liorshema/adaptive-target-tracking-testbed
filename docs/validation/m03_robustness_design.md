## Existing causal contract (read-only audit)

1. State is `[x,y,yaw,v,omega,q,dq]`, dimension 5+2N, in odom. Mean propagation is exact constant planar twist plus constant joint speeds. Existing acceleration and contact-slip Q discretization remain unchanged.
2. Factory constructs the configured initial mean/covariance (base mean zero, base covariance diagonal 1), timestamp initially unset. This is an uncertain prior, not a trusted absolute reference. World/odom spawn transform is supplied by TF, not estimator math.
3. Every first external pose can immediately reach the ordinary EKF after frame/child/quaternion/SPD/age validation and shared source-time reorder. No startup consistency check exists.
4. Pose H selects x/y/yaw. Wrapped innovation r; S=HPH'+R, NIS=r'S^-1r; unchanged gate 11.345. R is transformed with the planar frame Jacobian, including off-diagonal terms. Simulation R is white+bias marginal variance: .04m white XY, 2deg yaw, .01m/.5deg fixed per-run calibration bias. Sampling10Hz, latency40–50ms, dropout5%. Bias is correlated across samples; this is not independent white bias.
5. Broad P admits a plausible first +1m,+1m,+.5rad outlier. P then contracts around that bad reference. Good subsequent poses fail the gate; rarer similarly corrupted observations reinforce the bad reference. Retained degraded run first commits at2.7s, accepts corrupted4.8/10.3s poses, and reaccepts nominal pose only15.1s.
6. When aiding disappears, wheel/joint EKF propagation continues and covariance grows through existing Q. There is no source-health state machine; source age appears only in diagnostics and does not determine full-state publication.
7. Current re-trust is a single NIS pass, including after sustained rejection. D917: several valid poses rejected around60s, then a ~29.6deg correction at60.25s. No multi-sample corroboration exists.
8. Controller consumes the ordinary full robot estimate; its adapter does not use covariance to establish global localization trust. Existing input freshness/finite/frame checks and actuator watchdogs remain authoritative. A fresh aggregate wheel/joint timestamp can mask old/untrusted absolute aiding. Historical invalid-control reasons must be classified separately; no evidence supports blaming every recorder gap on localization.
9. Correction belongs in existing `robot/planar_pose.py` (pure bounded acceptance policy), `robot_state_estimator.py` (same EKF update and explicit uncertainty addition), estimator factory/schema/config, and `nodes/estimation_node.py` (publication/health adapter). No simulation package move, new ROS node, second EKF, new launch hierarchy or controller changes.
10. Existing ROS messages/topics and update interface remain unchanged. A small generic PSD covariance-addition operation belongs inside the existing EKF. Constructor/factory accept the optional policy. Legacy/nonlocalized configurations keep strict ordinary behavior.

## Alternatives and selected method

- Increasing the NIS threshold or narrowing the initial prior: rejected; hides faulty evidence or invents prior certainty.
- Only increasing slip Q: rejected as a complete fix; cannot distinguish an initial corrupted observation from a plausible uncertain prior and unnecessarily changes every nominal propagation.
- Selected: causal finite-window source consistency before first commit and after rejection/loss, followed by one ordinary current-observation EKF update. Confirmed model mismatch permits explicit PSD uncertainty growth, rather than silently accepting a bad NIS or resetting the mean.

Policy data are only source-time pose innovations and R, motion-compensated by the ordinary wheel/joint-propagated prior. Keep at most5 observations, expire beyond.8s, require4 inliers including the newest observation and source span>=.30s. Robust component median (yaw chart around a reference) selects a representative actual observation. Each residual offset must be consistent with that representative using Ri+Rref+Qrelative(dt); Qrelative is the existing base process covariance over the relative interval at the current frozen linearization. Common calibration bias cancels approximately in differences; counting marginal bias twice is conservative. No median/window average is fused and no R/sqrt(N) precision is claimed. Only the current source observation is fused once. Median selection and a linear scan avoid an all-pairs graph or unbounded history.

Modes: initializing, tracking, validating, degraded. One failed NIS enters validation; no state/covariance update occurs from that observation. Last-accepted source age>.35s marks degraded. Full stamped estimates are withheld while untrusted; wheel/joint updates and legacy diagnostic vector continue internally. Ordinary controller freshness then expires and existing actuation safety holds. With5 samples at10Hz, the evidence window naturally spans~.4s, longer than the unchanged.2s control freshness budget; no cosmetic output smoothing or watchdog change is made. New source consensus is necessary after rejection/outage; clock reset recreates the policy and clears all prior-epoch evidence. Disabled localization uses ordinary wheel-only publication. Enabled localization with no source remains explicitly untrusted and withholds control input, rather than claiming wheel-only global accuracy.

On corroborated recovery with NIS above gate, add rank-one pose uncertainty before the update: for B=H' r, deltaP=k B B', k=1/targetNIS-1/currentNIS, targetNIS=3 (expected dimension), giving NISnew=targetNIS by Sherman–Morrison. Add only positive k; validate finite symmetric PSD increment in the EKF, preserve mean/timestamp and joints, then recompute NIS and perform the existing wrapped/Joseph update. This is an explicitly reported fault-conditioned adaptive covariance approximation, not an exact Bayesian posterior. It increases uncertainty instead of manufacturing measurement precision. Never apply it to a lone outlier. Recovery diagnostics report original/recomputed NIS, covariance addition, pose correction and event count.

Assumptions/limits: enough causal, mutually consistent, correctly calibrated observations in a bounded window, relative motion uncertainty appropriate over<=.8s, unambiguous local heading chart. At most one arbitrary outlier in a qualifying5-sample window; longer bursts postpone acceptance until4 valid samples return. A coherent majority-corrupted source, unknown persistent map bias or arbitrarily wrong motion/noise model cannot be certified by one sensor. No guarantee that future readings become correct. Insufficient evidence causes continued uncertainty/withholding; no forced reset or stale acceptance.
